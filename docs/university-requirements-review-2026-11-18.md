# 41 所美国院校本科新生要求复核

复核日期：2026-11-18。基线：2026–27 申请季 / Fall 2027 入学，面向国际本科新生。

逐一检查了 41 条院校记录。40 条已完成本次测试与英语核心政策复核；Columbia 的英语和材料仍待核验。UNC 与 UF 另有两处官方来源冲突，均单独展示，不能视为全部要求已确认。这里的复核范围主要是测试政策、英语考试及豁免路径；材料清单按已读官方页面修正，未逐专业穷尽作品集、国别课程、预算与资助资格。

推荐/竞争力分数与硬性最低分分开；未读到明确新制 TOEFL 门槛时不自行换算。校方可选或不考虑 SAT/ACT 时，不因 Profile 缺少 SAT/ACT 扣分。

## 待确认与官方页面差异

- Columbia：已读 [2026-06-12 校方公告](https://communications.news.columbia.edu/news/update-columbia-college-and-columbia-engineering-testing-policy)，确认 Fall 2027 可选、Fall 2028 起须 SAT/ACT，困难者可申请 waiver。本科英语和材料页面仍返回 403；保留待核验，未套用 GS、Combined Plan 或研究生要求。
- UNC Chapel Hill：已读 [国际新生清单](https://admissions.unc.edu/apply/types-of-applications/international-first-year-students/) 和 [通用新生清单](https://admissions.unc.edu/apply/types-of-applications/first-year/)。两页对 RD supporting materials / test scores 分别列 2/15 与 2/21，需按较早日期准备并通过 MyCarolina / 招生办确认。
- UF：[本科招生办](https://admissions.ufl.edu/apply/freshman/international) 要求境外课程逐科评估并计算 GPA；[本科 catalog](https://catalog.ufl.edu/UGRD/admission/) 对新生则写鼓励而非必需。两种说法同时保留，须核对 Gator Portal / 招生办。catalog 已确认非英语母语者须 TOEFL 或 IELTS，但未取得本科新生数值要求；未借用 UF Online、转学或研究生门槛。招生办 [2026–27 日期表](https://admissions.ufl.edu/apply/freshman/deadlines) 与 catalog 的申请轮次也不完全一致，本次轮次按当季招生办日期表记录。

## 主要修正

- Yale 补齐 DET；Princeton 明确 Fall 2027 可选、Fall 2028 起必交；Columbia 同期恢复必交并可申请困难豁免。
- Vanderbilt 明确 Fall 2027/2028 可选，Fall 2029 起必交。
- CMU 按计算机、其他学院灵活路径、艺术可选分开；Dartmouth 按高中所在地处理替代路径。
- Berkeley TOEFL 旧制最低 90；UCSD 旧制 83、IELTS 7；UCLA 的竞争力参考分不当成统一硬门槛。
- Penn 为 Counselor + 1 封教师推荐；Northwestern 为学校推荐 + 1 封教师推荐；NYU 为至少 1 封（不限定教师），并须 STARS。
- Georgetown 现支持 Common Application；GT 的 DET 仅为补充，不能代替 USG 认可英语路径。
- UNC 按 4.0 制加权 GPA 2.8 分流：达到可选，未达到须 SAT ≥ 930 / ACT ≥ 17。其他分制、未加权 GPA 不自动换算；英语参考分不是硬性最低分。
- 英语主授课勾选不再对所有学校自动豁免；不接受的考试版本不会同时显示总分通过。未核实的分数阈值不会显示分数通过。
