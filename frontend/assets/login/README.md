# Login reference artwork

These assets come from the user-provided reference video
f80ff90fe5c8c2b757df72760c16b1f3.mp4 (1008 x 720, 30 fps).

- intro.mp4 contains the first 38 frames: the running cat, title entrance,
  and form reveal. It ends before the example name and password are typed.
- The transparent PNGs preserve the reference's original drawn title, field
  labels, underlines, cat, red login text and button outline.
- dot.png preserves the last ink mark in the reference's exit.
- login.css uses the source coordinates for the interactive form, and
  recreates its button compression and stepped exit around (514, 408).
- Real credentials are native inputs. Example credentials from the video
  are not prefilled. The password is visible in blue to match the reference.

The current site uses the static artwork and shared notebook.css background. The intro video and dot are retained for future animation work and are not loaded by the static login page.
